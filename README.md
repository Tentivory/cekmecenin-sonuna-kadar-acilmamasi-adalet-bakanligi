# T.C. Adalet Bakanlığı
## Çekmecenin Sonuna Kadar Açılmaması Yargı Tıkanıklığı Yazılımı

> Çekmece ya sonuna kadar açılır ya da dosya geride kalır. Ortası yoktur. Ortası istinaftır.

Bu depo, mutfak, çalışma masası veya nöbetçi hâkim odasındaki çekmecenin **son bir karış yerde takılmasını** resmi yargı olayı kabul eder. Takılma bir mobilya kusuru değildir. Takılma duruşma günüdür. Ray usuldür. Kulp karardır. Arkada kalan kaşık gizli ektir.

Yazılım **gerçekten çalışır**. Çalışması, dosyanın kapanmasını sağlamaz.

## Teşhis

Vatandaş çeker. Saniye 1.4'te ray durur. Vatandaş şunu söyler:

> "Biraz çekince gider."

Bakanlık bu cümleyi **istinaf dilekçesi** sayar. İkinci hamle kuvvet değildir. İkinci hamle temyizdir.

## Kuruluş

Python 3.9+ yeterlidir. Bağımlılık yoktur. Yarım açık çekmece her yerde vardır.

```bash
python3 bakanlik.py
python3 bakanlik.py --mekan mutfak --takilma 4
python3 bakanlik.py --surum
```

## Sık sorulan sorular

**Çekmeceyi söküp rayı yağlasam?**  
Yağlama usul ekonomisine aykırıdır. Usul, sıkışan yerde bekler.

**Başka çekmeceye geçsem?**  
Nakil için görevsizlik kararı gerekir. Bu yazılımda görevsizlik yoktur, hayattadır.

**Bu şaka mı?**  
Hayır. Şaka, çekmece tam açıldıktan sonra söylenir. Yarım açıklık varken her şey resmi tutanaktır.
